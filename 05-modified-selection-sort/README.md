# Модифицированный метод простого выбора и обработка матриц

## Задача
Реализовать модифицированный алгоритм сортировки простого выбора (двусторонний выбор). Дополнительно реализовать поиск максимального элемента ниже побочной диагонали и минимального выше главной диагонали в квадратной матрице.

## Контекст
Лабораторная работа по алгоритмам и структурам данных. Требовалось представить алгоритм в виде блок-схем, схем Насси-Шнейдермана и диаграмм Дракон, а также оценить сложность.

## Моя роль
Разработка алгоритма, реализация на C++, защита от некорректного ввода (буферный ввод через `cin.getline` и посимвольная проверка), написание тестов.

## Процесс
- Изучен классический метод простого выбора и его модификация (поиск минимума и максимума за один проход, обмен с двух концов).
- Реализованы функции ввода с защитой от символов (`Proverka_na_chislo` и `Perevod_v_chislo`).
- Реализован ввод и обработка матрицы с проверкой на минимальный порядок (n >= 2).
- Оценена временная и емкостная сложность алгоритма (Θ(n²) по времени).

## Инструменты
C++, std::cin / std::cout, динамические массивы (new/delete).

## Результат
Программа корректно сортирует массивы любой длины и находит элементы в матрице согласно заданию. Ввод защищен от букв и спецсимволов, программа не падает при некорректных данных.
