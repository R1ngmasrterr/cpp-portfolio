# Портфолио C++ проектов

**Студент:** Ефремов Кирилл 
**Специальность:** Разработка IT-систем и мультимедийных приложений (2 курс)

В данном репозитории представлены ключевые учебные проекты на C++, демонстрирующие навыки работы с памятью, алгоритмами, структурами данных и ООП.

## Проекты

### 1. Модифицированный алгоритм Бута (Курсовая работа)
Реализация арифметики многократной точности (чисел произвольной длины) в дополнительном коде.
*   **Реализовано:** Операции сложения, инверсии знака, логического и арифметического сдвига, а также умножение по модифицированному алгоритму Бута для массива 32-битных слов (little-endian). Знаковое расширение и нормализация.
*   **Тестирование:** Проект покрыт модульными тестами (18 тестов) с использованием Microsoft Unit Testing Framework.
*   **Стек:** C++, std::vector, uint32_t, побитовые операции.
*   **Папка:** [03-booth-algorithm](./03-booth-algorithm/)

### 2. Модифицированный метод простого выбора и обработка матриц (Лабораторная работа)
*   **Реализовано:** Двусторонняя сортировка простого выбора (поиск min и max за один проход). Дополнительно реализован поиск элементов выше главной и ниже побочной диагонали матрицы.
*   **Особенности:** Защита от некорректного ввода (посимвольная валидация строки). Оценена временная сложность алгоритма (Θ(n²)).
*   **Стек:** C++, динамические массивы, работа с памятью.
*   **Папка:** [05-modified-selection-sort](./05-modified-selection-sort/)

### 3. Двунаправленный (двусвязный) список (Лабораторная работа)
*   **Реализовано:** Формирование списка целых чисел, добавление нового элемента после узла с минимальным значением.
*   **Особенности:** Работа с указателями `next` и `pred`, обработка граничных случаев (вставка в начало/конец), безопасная очистка памяти.
*   **Стек:** C++, структуры, указатели.
*   **Папка:** [02-doubly-linked-list](./02-doubly-linked-list/)

### 4. Обработка исключений: Класс Sfera (Лабораторная работа)
*   **Реализовано:** Класс «Сфера» с валидацией данных. Демонстрация генерации и перехвата исключений (блоки `try`, `catch`, `throw`).
*   **Особенности:** Обработка ввода спецсимволов вместо чисел, перехват системных исключений (`std::invalid_argument`, `std::out_of_range`).
*   **Стек:** C++, ООП, std::string, исключения.
*   **Папка:** [04-exceptions](./04-exceptions/)

### 5. Однонаправленный (односвязный) список (Лабораторная работа)
*   **Реализовано:** Создание списка вещественных чисел, вычисление среднего арифметического первого и последнего элементов.
*   **Особенности:** Использование указателя `tail` для добавления элементов за O(1).
*   **Стек:** C++, указатели, динамическая память.
*   **Папка:** [01-singly-linked-list](./01-singly-linked-list/)
