# Модифицированный алгоритм Бута (Арифметика многократной точности)

## Задача
Разработать программный модуль на C++ для выполнения арифметических операций с целыми числами произвольной длины (многократная точность). Реализовать умножение по модифицированному алгоритму Бута, а также сложение, сдвиги и инверсию знака в дополнительном коде.

## Контекст
Курсовая работа, 1 курс. Ограничения: использование стандартной библиотеки C++.

## Моя роль
Полная реализация проекта: от изучения теоретической базы (дополнительный код, little-endian представление) до написания кода и покрытия его модульными тестами.

## Процесс
1. Изучены принципы хранения длинных чисел в виде массива 32-битных слов.
2. Реализовано знаковое расширение и нормализация.
3. Написаны функции базовых операций (сложение, сдвиги, унарный минус).
4. Классический алгоритм Бута адаптирован для работы с массивами слов (регистр P размером 2k слов).
5. Написано 18 модульных тестов (в отдельном проекте Visual Studio), включая граничные случаи и отрицательные числа.

## Инструменты
C++11/17, std::vector, uint32_t, Visual Studio 2022, MS Unit Testing Framework.

## Результат
Все 18 модульных тестов успешно пройдены. Программа корректно умножает положительные и отрицательные числа произвольной длины, корректно обрабатывает переполнения и переносы.
