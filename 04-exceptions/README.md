# Обработка исключений (Класс Sfera)

## Задача
Написать программу, создающую класс «Сфера» (радиус, координаты центра x, y, z). Обработать исключения: ввод пользователем специального символа вместо целого числа, а также невозможность создания сферы (радиус <= 0).

## Контекст
Лабораторная работа по объектно-ориентированному программированию и обработке исключений.

## Моя роль
Реализация класса, механизма генерации и перехвата исключений (`throw`, `try`, `catch`), валидация пользовательского ввода.

## Процесс
- Создан класс `Sfera` с валидацией радиуса в конструкторе (выбрасывает `std::invalid_argument`).
- Написана функция `VvodCisla`, которая считывает строку, проверяет её на наличие нецифровых символов (выбрасывает `const char*`) и конвертирует через `stoi` с защитой от переполнения (`std::out_of_range`).
- В `main` реализован цикл запроса данных с обработкой всех типов исключений через три блока `catch` (строковые литералы, стандартные исключения, универсальный обработчик).
- Реализован повторный запуск программы без перезапуска.

## Инструменты
C++, ООП, `std::string`, `std::stoi`, блоки `try-catch`, стандартные исключения (`std::invalid_argument`, `std::out_of_range`).

## Результат
Программа защищена от падений: она корректно обрабатывает ввод букв вместо цифр и попытку создать сферу с отрицательным радиусом, предлагая повторить ввод. Код демонстрирует понимание работы с исключениями разных типов.
