# Двунаправленный (двусвязный) список

## Задача
Сформировать двунаправленный список целых чисел. Добавить в список новый элемент после элемента с минимальным числовым значением в информационном поле.

## Контекст
Лабораторная работа по динамическим структурам данных, 2 курс.

## Моя роль
Реализация структуры `Node` (с указателями `next` и `pred`), функций добавления в конец, поиска минимума, вставки после заданного узла и безопасной очистки памяти.

## Процесс
- Спроектирована структура узла списка.
- Реализована функция добавления в конец с обновлением указателей `head` и `tail`.
- Написана функция поиска минимального элемента (линейный проход по списку).
- Реализован алгоритм вставки нового узла с перенаправлением указателей `pred` и `next` для соседних элементов. Отдельно обработан случай, когда минимальный элемент является хвостом списка.
- Предусмотрена очистка памяти для предотвращения утечек.

## Инструменты
C++, указатели, динамическая память (new/delete).

## Результат
Программа корректно формирует список, находит минимум и вставляет элемент после него, аккуратно работая с указателями на предыдущий и следующий элементы. Реализована защита от ввода отрицательного количества элементов.
