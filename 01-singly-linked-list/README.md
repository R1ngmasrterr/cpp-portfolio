# Однонаправленный (односвязный) список

## Задача
Сформировать односвязный список вещественных чисел. Найти среднее арифметическое головного (первого) и концевого (последнего) элементов списка.

## Контекст
Лабораторная работа по динамическим структурам данных, 2 курс.

## Моя роль
Реализация структуры `Node`, функций добавления в конец, печати списка, вычисления среднего и очистки памяти.

## Процесс
- Создана структура узла с указателем на следующий элемент.
- Реализована функция `DobavVKonec` с поддержкой указателя `tail` для быстрого добавления за O(1).
- Реализован проход по списку для доступа к последнему элементу и вычисления среднего.
- Написана функция очистки памяти, чтобы избежать утечек.
- Добавлена проверка на корректность ввода количества элементов.

## Инструменты
C++, указатели, структуры, динамическая память (`new`/`delete`).

## Результат
Программа успешно создает список, выводит его и находит среднее арифметическое первого и последнего элементов (корректно работает даже для списка из одного элемента). Память полностью освобождается после завершения работы.и
